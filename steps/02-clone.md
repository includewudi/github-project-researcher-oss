# Step 2: Clone to Local Library

## Clone

```bash
mkdir -p ~/.github-researcher/projects/{owner}
git clone https://github.com/{owner}/{repo}.git ~/.github-researcher/projects/{owner}/{repo}
```

**Large repo (>100MB):**
```bash
git clone --depth 1 https://github.com/{owner}/{repo}.git ~/.github-researcher/projects/{owner}/{repo}
```

## Directory Convention

```
~/.github-researcher/projects/
├── {owner}/
│   ├── {repo}/
│   │   ├── RESEARCH.md    ← Generated by this skill
│   │   └── ... (project files)
│   └── {repo2}/
└── KNOWLEDGE_BASE.md      ← Accumulated learnings
```

## Edge Cases

| Case | Action |
|------|--------|
| Clone fails (SSH) | Use HTTPS instead |
| Clone fails (HTTPS) | Check network, try `gh repo clone` |
| Repo already cloned | `git pull` to update |
| Disk space low | Use `--depth 1` + `--single-branch` |
